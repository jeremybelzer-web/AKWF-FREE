# Combo Organ

Transistor combo voicings (Farfisa / Vox / spinet families).

- Format: 600 samples, 16-bit, 44100 Hz, mono (AKWF cycle)
- Pitch keycenter: MIDI 38 (cycle ≈ 73.5 Hz)
- License: CC0-1.0 (same as AKWF)
- Instrument: `organ-combo.sfz` (looped cycle; C0–B0 keyswitches)
- Manifest: `organ-combo.json`

Each registration has a synthesized cycle and the closest `AKWF_eorgan` wave (`*__akwf_*`).
