# Organ sound packs (E1 GO (8))

Three playable organ packs in the AKWF cycle format (600 samples, 16-bit, 44.1 kHz, mono).

| Pack | Folder | Waves |
| --- | --- | --- |
| Drawbar Organ | `organ-drawbar/` | 12 registrations (+ closest AKWF_eorgan) |
| Pipe Organ | `organ-pipe/` | 12 registrations (+ closest AKWF_eorgan) |
| Combo Organ | `organ-combo/` | 12 registrations (+ closest AKWF_eorgan) |

Load `*.sfz` in any SFZ sampler, or the JSON cycles in a web/PMW oscillator. License is CC0-1.0.
